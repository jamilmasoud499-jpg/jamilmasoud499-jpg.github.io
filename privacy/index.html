Privacy Policy

Last updated: September 29, 2026.

Information used

JARVIS processes the authorized Telegram user ID, commands, video, caption and privacy choice to prepare the requested TikTok post. When the user connects a TikTok account, TikTok provides authorization credentials and account information required for the integration.

Purpose

JARVIS uses this information to restrict bot access, display account posting options and submit the video only after the user requests publication. The desktop integration operates on the user’s computer. Telegram and TikTok also process data under their own policies.

Control

The user can stop the local bot, remove locally stored integration data and revoke the app’s access in TikTok settings. This website itself does not receive videos or TikTok login credentials.
